# Murilo Fotos IA

Landing page de ensaios fotográficos com IA.

- `index.html`: página inicial (antes e depois, depoimentos e quiz inicial)
- `quiz.html`: perguntas do quiz
- `resumo.html`: resumo das respostas, com o nome da pessoa, e botão para o checkout da Cakto
- `img/`: imagens da página

Meta Pixel: 262042519903496 (PageView, QuizIniciado, QuizConcluido, InitiateCheckout).
